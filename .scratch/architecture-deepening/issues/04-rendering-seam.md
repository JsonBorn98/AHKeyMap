# 04 — Give rendering a seam

Status: resolved

Depends on: [01](01-deepen-path-c-engine.md) (**hard** — the design requires `PathCEngine.Commit()` to return registration errors), [02](02-collapse-config-working-copy.md) (**hard** — rendering triggers through `ConfigStore.OnChanged` and reads store state), [03](03-one-mapping-schema.md) (soft — sequential churn only). Without 01+02 this ticket's interfaces have nothing to attach to.

## Problem

Rendering is smeared as side effects across domain modules, with dependencies running **upward**:

- `Config.ahk` writes GUI widgets (`RefreshConfigList:148-182`, `RefreshMappingLV:371-394`, `UpdateStatusText:220-253`) and calls **into** GuiMain (`SetStatusDetailHover` at `Config.ahk:250` — a core→ui call).
- `ReloadAllHotkeys` calls `UpdateStatusText` (`HotkeyEngine.ahk:211`) and outputs via the `HotkeyConflicts`/`HotkeyRegErrors` globals.
- `StatusHasWarning` is written by Config (`:240`) and read by GuiMain's hover handlers (`GuiMain.ahk:211,223`).
- Headless operation survives only on the `StatusText = ""` test-mode guard (`Config.ahk:241-242`).
- `RefreshConfigList` calls the GUI event handler `OnConfigSelect` (`Config.ahk:165`) — a Config→GuiEvents→Config bounce.

## Decisions (grilled 2026-09-02, all confirmed)

1. **Render moves to the widget owner**: `RefreshConfigList`/`RefreshMappingLV`/`UpdateStatusText` move into `src/ui/GuiMain.ahk`, consolidated behind one render-from-state entry with granular helpers underneath. Config.ahk completes its ticket-02 slimming into pure INI I/O.
2. **Engine output becomes return values**: `ReloadAllHotkeys()` returns `{conflicts: [...], regErrors: [...]}`; `DetectHotkeyConflicts` becomes a pure function returning the conflicts array; the `HotkeyConflicts` and `HotkeyRegErrors` globals are deleted. `PathCEngine.Commit()` (ticket 01) returns its registration-error keys instead of appending to a shared global; `ReloadAllHotkeys` concatenates. The **UI layer** holds the last result for `OnStatusTextClick`'s detail popup.
3. **Render triggers through an OnChanged seam**: `ConfigStore` (ticket 02) exposes an `OnChanged` callback slot; the GUI registers `RenderFromState` at startup. The store chokepoint becomes persist → reload → `OnChanged(reloadResult)`. Core never calls ui; headless tests register nothing and the store stays testable. One subscriber = hypothetical seam, kept because it inverts the dependency direction.
4. **View-model purity**: render splits into pure builders — status-summary text + warning flag, mapping row data, process-scope display (`FormatProcessDisplay`, already pure) — plus thin widget writes. Unit tests hit the builders; the gui suite keeps smoking the real window.
5. **Rollout**: single commit after 01-03, patch bump (`2.9.5` → `2.9.6`).

## Changes by file

- `src/ui/GuiMain.ahk` — absorbs the three render functions; `StatusHasWarning` becomes ui-written (render's output, no longer Config's); `OnStatusTextClick` reads the ui-held reload result; the `StatusText = ""` guard is deleted (render only runs when the window exists).
- `src/core/Config.ahk` — loses all render functions; pure INI I/O.
- `src/core/HotkeyEngine.ahk` — `ReloadAllHotkeys` returns the result Map and drops the `UpdateStatusText` call; `DetectHotkeyConflicts` returns instead of writing a global; the `ReloadConfigHotkeys(name)` wrapper (already a full-reload alias) is deleted and callers go through the store.
- `src/core/PathCEngine.ahk` — `Commit()` returns its registration-error keys (completes ticket 01's deferred cleanup).
- `src/ui/GuiEvents.ahk`, `src/ui/MappingEditor.ahk` — no explicit render/reload calls remain; everything flows through the store chokepoint + OnChanged.
- `src/AHKeyMap.ahk` — startup (`:211-214`) and language switch (`:262-268`) rewire through store + callback; `HotkeyConflicts`/`HotkeyRegErrors` declarations deleted; version bump.
- `tests/support/TestBase.ahk` — `StatusHasWarning` mirror removed from `ResetAppState` (ui-owned now; keep only if the gui suite still needs a reset).
- `tests/integration/hotkey_engine_state.test.ahk` — `ReloadAllHotkeys` assertions switch to the return value; new `tests/unit/view_models.test.ahk` covers the builders.
