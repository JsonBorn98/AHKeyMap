## Problem

KeyCapture reaches into MappingEditor's widgets: `ApplyCapturedKey` (`KeyCapture.ahk:458-470`) writes `EditModifierEdit`/`EditSourceEdit`/`EditTargetEdit` directly, and `UpdatePassthroughState` (`:473-479`) manipulates the editor's checkbox — its own comment admits it "must be called from the MappingEditor module". The two modules share a hidden protocol: a custom `.ahkKey` property stuffed onto Edit controls (display string in `.Value`, AHK syntax in `.ahkKey`; set at `MappingEditor.ahk:69-81` and in `ApplyCapturedKey`, read at `OnEditMappingOK:107-109` and `UpdatePassthroughState:475`). Meanwhile `FinishCapture`'s real logic — modifier folding and `ModifierPrefixToKeyName` fallback (`:285-315`, BUG-005 territory) — is testable only with a live capture window.

## Decisions (grilled 2026-09-02, all confirmed)

1. **Per-call completion adapter**: `StartCapture(target, onCaptured)`; on completion the capture session invokes `onCaptured(ahkKey, displayKey)` once. `OnCaptureModifier/Source/Target` pass the target plus the editor's callback. No persistent callback slot to register/clean up.
2. **The editor owns its protocol**: `UpdatePassthroughState` moves into `MappingEditor.ahk` wholesale; the `.ahkKey` convention becomes editor-internal (it owns the controls and both the read and write sides). KeyCapture's interface loses the four control globals (`EditModifierEdit`/`EditSourceEdit`/`EditTargetEdit`/`EditPassthroughCB`).
3. **Pure folding function**: extract `BuildAhkKey(captureKeys, targetMode)` from `FinishCapture` (modifier folding, main-key selection, modifier-only fallback via `ModifierPrefixToKeyName`, wheel immediate-confirm input). `FinishCapture` becomes thin glue around it.
4. **Single commit**, patch bump, after ticket 02.

## Changes by file

- `src/core/KeyCapture.ahk` — `StartCapture` signature; `ApplyCapturedKey`/`UpdatePassthroughState` deleted; the four editor-control `global` declarations removed; `BuildAhkKey` extracted. Its own eight capture-state globals stay (well-contained already).
- `src/ui/MappingEditor.ahk` — gains the completion callbacks (write `.Value` + `.ahkKey` on its own controls, then `UpdatePassthroughState` for the modifier case) and the moved `UpdatePassthroughState`; capture buttons bind to the new `StartCapture(target, callback)` entries.
- `tests/unit/keycapture_helpers.test.ahk` — extend with `BuildAhkKey` cases: modifier-only (fallback to `ModifierPrefixToKeyName`), modifier+key, modifier+wheel, multi-key keeps largest combo, empty capture.
