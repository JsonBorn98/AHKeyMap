# 02 — Collapse the config working copy into a config store

Status: done — landed in PR #2 (commit e229f50)

Depends on: [01](01-deepen-path-c-engine.md) (soft — both edit the HotkeyEngine skeleton, the `AHKeyMap.ahk` globals block, and the test base's state reset; landing 01 first avoids rebasing onto its surgery). Logically this ticket could stand alone; the dependency is churn-avoidance.

## Problem

The selected config exists twice: as a record in `AllConfigs` and exploded into nine globals (`CurrentConfigName`, `CurrentConfigFile`, `CurrentProcessMode`, `CurrentProcess`, `CurrentProcessList`, `CurrentExcludeProcess`, `CurrentExcludeProcessList`, `CurrentConfigEnabled`, `Mappings`). Every mutating handler must re-perform an undocumented liturgy — mutate `Current*` → `SaveConfig()` → `RefreshMappingLV()` → `ReloadConfigHotkeys()` — duplicated at `MappingEditor.ahk:142-145`, `GuiEvents.ahk:327-329`, `:351-354`, `:270-272`, with `OnToggleEnabled` (`GuiEvents.ahk:41-45`) diverging (sync + `SaveEnabledStates`, no `SaveConfig`) because `enabled` persists to `_state.ini` rather than the config file.

Verified fact: no code path mutates `Mappings` without immediately saving, and the edit dialog's Cancel never touches it — the `LoadConfigToGui` deep copy (`Config.ahk:272-278`) defends against a phantom. The dual representation is pure ritual.

## Decisions (grilled 2026-09-02, all confirmed)

1. **Class module**: `class ConfigStore` + lazy static `ConfigStore.Instance` (same pattern as ticket 01). It owns `AllConfigs`, the selection (`SelectedName`), and every mutation. Suggested file: `src/core/ConfigStore.ahk`; Config.ahk slims to pure INI I/O (`GetConfigList`, `LoadConfigData`, `ParseProcessList`, `IsValidConfigName`, serialization, `SaveEnabledStates`).
2. **Delete the working copy**: all nine `Current*` globals and `SyncCurrentToAllConfigs` disappear. Readers use the selected record in the store. `MappingEditor` keeps its current pattern of rebuilding a fresh Map from its controls, so OK becomes one store call and Cancel stays free. The force-reload trick at `src/AHKeyMap.ahk:262-264` (clearing `CurrentConfigName`) becomes an explicit `ConfigStore.Instance.Select("")` / re-select.
3. **Semantic method set, not a generic apply**: each method runs the single chokepoint internally — persist (atomic config write + `SaveEnabledStates`) → `ReloadAllHotkeys()` → render (existing `Refresh*`/`UpdateStatusText` calls, unchanged; consolidating those belongs to candidate 4, out of scope).
4. **Uniform full persist**: every mutation, including `SetEnabled`, runs the same chokepoint. One redundant atomic write per toggle buys the no-special-cases invariant; externally visible behavior is unchanged.
5. **Own commit**: patch bump from whatever ticket 01 shipped (`2.9.3` → `2.9.4`).

## Interface (semantic methods, each = mutate + persist + reload + render)

```
ConfigStore.Instance.Select(name)
ConfigStore.Instance.SetEnabled(flag)
ConfigStore.Instance.SetScope(mode, procStr)        ; owns the include/exclude/global branch consistency
ConfigStore.Instance.AddMapping(mapping)
ConfigStore.Instance.ReplaceMapping(index, mapping)
ConfigStore.Instance.DeleteMapping(index)
ConfigStore.Instance.CreateConfig(name, mode, procStr)
ConfigStore.Instance.CopyConfig(newName)
ConfigStore.Instance.DeleteConfig()                 ; absorbs the FileDelete in GuiEvents.ahk:389-404
```
